# @saloni/engine

محرك الجدولة — منطق نقي بلا قاعدة بيانات ولا شبكة (التصميم §5). كل قاعدة معتمدة لها اختبار باسم قرارها.

| الملف | المسؤولية |
|---|---|
| `timeline.ts` | حساب الأوقات المتوقعة، الاستراحات وفترات «حاضرون فقط» (ق33)، التجميد عند الانقطاع (§4)، تجاوز الإغلاق (ق24) |
| `placement.ts` | إدراج حجز جديد: لا يتأخر أحد (ق4)، هامش ملء الفراغ (ق19)، الإلحاق فقط عند الانقطاع (ق3) |
| `assignment.ts` | «الأسرع» (§5.4) والحجز عند حلاق محدد |
| `policy.ts` | الإعدادات الافتراضية، التنبيه الإلزامي (ق5/ق23)، حالة يوم الحلاق (ق3/ق26)، تنبيه تجاوز المدة (ق27) |
| `queue-ops.ts` | الاستدعاء، البدء/الإنهاء، التأجيل ولم يحضر (ق10/ق21/ق22)، الإلغاء (ق29)، العروض (ق13)، تعديل الوقت (§5.12) |
| `duration.ts` | تعلّم المدة (ق11) |
| `sim/` | محاكي يوم عمل لضبط الإعدادات |

```
npm test                 # الاختبارات
npm run simulate -- --seeds 20 --barbers 3 --demand 5 --lead 20
```
