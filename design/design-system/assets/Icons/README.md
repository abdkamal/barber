# الأيقونات

Phosphor Icons (رخصة MIT) بوزن **regular**. النسخ هنا ملوّنة بـ `#4a6067` (قيمة `ink-muted` الفاتحة) لعرضها فقط؛ في الواجهات تُستخدم الأيقونات بلون النص المحيط (`currentColor`) عبر المكوّن `Icon` في الويب، وحزمة `phosphor_flutter` في التطبيقات بالأسماء نفسها.

- حجم 20px داخل النص والأزرار، 24px في الشريط السفلي والأزرار الكبيرة، 32px في الحالات الفارغة.
- الأيقونات الاتجاهية (`caret-left`، `caret-right`، `arrow-u-up-left`، `navigation-arrow`) تُعكس في RTL.
- لا رموز تعبيرية (emoji) بديلًا عن الأيقونات.
