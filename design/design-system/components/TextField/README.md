# TextField

حقل إدخال بتسمية ظاهرة دائمًا. يمرر المستهلك `label` و`value` و`type` واختياريًا `prefix` (مثل `+966`) و`hint` و`error` و`placeholder` و`inputMode`.

- رقم الهاتف: `prefix` + `dir="ltr"` + `inputMode="tel"` — الأرقام تبقى من اليسار لليمين داخل واجهة عربية.
- كلمة المرور: `type="password"` يضيف زر الإظهار/الإخفاء تلقائيًا.
- رسالة الخطأ تقول ما الخطأ وكيف يُصلح: «رقم الهاتف يجب أن يكون 9 أرقام بعد 966+»، لا «إدخال غير صالح».
- لا تستخدم النص النائب بديلًا عن التسمية.
