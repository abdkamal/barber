# CatalogItem

خدمة أو منتج في صفحة «حول الصالون» (ق37). يمرر المستهلك `kind` (`service`/`product`) و`name` و`price` و`currency` و`description` و`features` و`minutes` (للخدمة) و`image` اختياريًا.

- بلا صورة: أيقونة على خلفية ملونة (مقص للخدمة، علبة للمنتج).
- المنتجات للعرض فقط — «متوفر في الصالون»، لا زر شراء.
