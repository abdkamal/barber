# BarberOption

خيار الحلاق في شاشة الحجز. يمرر المستهلك `name` و`nextAt` (أقرب بدء) و`wait` و`selected`، أو `fastest` لخيار «الأسرع»، أو `unavailable` مع `reason`.

- «الأسرع» أولًا دائمًا: يختار النظام من يبدأ الخدمة أبكر (التصميم 5.4)، ثم الحلاقون.
- الحلاق الغائب أو المتوقف حجزه يظهر معطلًا مع السبب، لا يُخفى.
