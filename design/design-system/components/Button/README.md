# Button

الزر لكل إجراء يغيّر شيئًا. يمرر المستهلك `children` (فعل صريح: «إنهاء الخدمة»، «احجز هذا الوقت») و`variant` و`size` واختياريًا `icon` و`block` و`loading` و`onClick`.

- `primary`: إجراء واحد أساسي في الشاشة. `secondary`: البديل. `ghost`: إجراء ثانوي داخل بطاقة. `danger`: إلغاء، «لم يحضر».
- `size="lg"` (60px) لأزرار الحلاق الأساسية: بدء، إنهاء، تأكيد الدفع — يستخدمها أثناء العمل.
- لا زرّان `primary` في منطقة واحدة. التسمية فعل، لا «موافق» أو «نعم».
- `loading` يمنع الضغط المزدوج أثناء الإرسال (مهم للحجز وتأكيد الدفع).
