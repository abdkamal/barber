# QueueProgress

شريط نقاط يوضح للزبون الأدوار المنجزة وموقع دوره، **دون أرقام** (ق39). يمرر المستهلك `done` (أدوار منجزة اليوم عند حلاقه، تُقصّ لآخر 3–4) و`ahead` (من أمامه) و`updated` واختياريًا `note`.

- مؤشر بصري مساعد تحت `EtaCard`؛ الوقت المتوقع يبقى المعلومة الأساسية.
- لا يُكتب عدد من أمامك نصًا. إذا تغيّر الطابور (طلب ساعة، تأجيل) يتغيّر الشريط، ويُشرح السبب في `EtaCard` عند تجاوز 30 دقيقة (ق5).
- نقطة الزبون أعرض وبلون الانتباه، والمنجز بلون الهوية.
