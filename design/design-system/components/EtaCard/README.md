# EtaCard

بطاقة المتابعة في تطبيق الزبون — أهم شاشة فيه. يمرر المستهلك `eta` و`ampm` و`status` و`barber` و`services` و`updated` واختياريًا `originalEta` و`reason` و`kind` و`live=false` مع `staleFor`.

- الوقت المتوقع هو البطل، لا «عدد من أمامك» (المتطلبات، حادي عشر).
- إذا تغير الوقت يظهر «كان متوقعًا ...» مع السبب — لا يُخفى التغيير (ق5).
- «آخر تحديث» ظاهر دائمًا. عند انقطاع الحلاق: `live=false` يرمّد الوقت ويظهر تحذير «تقديري» (التصميم 4).
