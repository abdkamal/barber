# CurrentServiceCard

بطاقة الخدمة الجارية أعلى شاشة الحلاق. يمرر المستهلك `customer` و`services` و`startedAt` و`elapsed` و`estimate` (بالدقائق) و`onEnd` و`onEdit`.

- عند تجاوز المدة المقدرة (100%، ق27): حد وعدّاد بلون الانتباه وتذكير — **لا إنهاء تلقائي**.
- زر «إنهاء الخدمة» كبير (`control-lg`)؛ بعده يظهر «تأكيد الدفع» كإجراء مستقل.
