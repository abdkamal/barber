# e2e — الاختبار الشامل على السيرفر الحقيقي

```bash
e2e/run.sh            # من أي مكان؛ يمرّر أي وسائط إضافية إلى `dart test`
E2E_PORT=3791 e2e/run.sh
```

ما يفعله `run.sh`:
1. يشغّل `dockerd` إن لزم، ثم PostgreSQL + PgBouncer من `infra/docker-compose.yml`.
2. يحذف قواعد `saloni_e2e_*` السابقة (لا يمس قواعد التطوير ولا `saloni_test_*`).
3. يبني `@saloni/engine`، يرحّل `saloni_e2e_directory`، ويشغّل السيرفر الحقيقي
   (`ts-node src/main.ts`) على المنفذ 3790 بقواعد `saloni_e2e_*` ورفع الصور في `e2e/.tmp/`.
4. يشغّل `dart test` هنا: `ApiClient` و`StaffSyncEngine` الحقيقيان من `packages/saloni_api`.

التدفق (`test/full_flow_test.dart`): تسجيل المالك صالونه ← تفعيله بأداة المورّد
(`src/cli/vendor.ts activate`) ← المدير يضيف خدمتين وحلاقين ودوامًا ويفعّل اعتماد الحسابات ←
زبون يسجّل (`ACCOUNT_PENDING`) ويُعتمد ويحجز ← زبون ثانٍ يحجز ثم ينقله المدير لحلاق آخر (ق25) ←
الحلاق يبدأ الخدمة وينهيها **دون اتصال** (رفض الحاضر محليًا، `since` ثابت) ثم `flushNow()` ←
تأكيد الدفع من الجهاز ← الزبون يرى الزيارة منجزة ومدفوعة ← تقرير المدير يعرض الإيراد.

المنطقة الزمنية للصالون تُختار (`Etc/GMT±N`) بحيث يكون وقته المحلي قرب الظهيرة، فيقع التدفق دائمًا
داخل دوام 06:00–22:00. سجل السيرفر: `e2e/.tmp/server.log` (يُطبع ذيله عند الفشل).
